# Merovingian 1.1.0

The local Architect Console now reflects the plugin, marketplace and knowledge
repository model, with administrative per-person catalog previews.

- Journal browsing renders sanitized Markdown, links previous entries and direct
  continuations, and offers a clickable 30/60-day activity calendar with person and
  date filters. Stable cursors preserve pagination while new entries are added.
- Journal reads and activity counts use personal authentication: authors see their
  own history and explicit Journal administrators can read the tenant history.
  Administrative graph credentials never serve as a fallback.
- The purpose graph renders locally, with keyboard navigation and selection
  highlighting. Browser payloads omit executable tool configuration and secrets.
- GitHub deployment reconciles review teams. MCP connection and operation errors
  distinguish failures and uncertain appends without exposing sensitive details.

Install with `bun add -g @supernova-labs/merovingian@1.1.0` and verify
`merovingian --version`. Independently pinned MCP runtimes must also be updated;
governance plugin versions are separate from the CLI package.

The next normal tenant deploy provisions the Journal timestamp index. Publishing
this release does not deploy tenants or migrate their data. The console remains a
trusted local operator tool, not a hosted multi-user application.

Implementation: [PR #46](https://github.com/supernova-labs/merovingian/pull/46)
and [PR #47](https://github.com/supernova-labs/merovingian/pull/47).
