# Friction record format

One friction per record — atomic. Structured markdown:

```markdown
## Friction
<one sentence: the gap between what is and what could be>

## Context
<what was being done when it ground · enough for a reader with zero session context>

## Cost
<what it cost: time, confusion, a workaround, a risk taken>

## Could be
<optional: the shape of better, if it's already visible — don't force a solution>
```
