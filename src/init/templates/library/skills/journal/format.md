# Journal record format

Structured markdown; every section optional except **Done**. Rich but scannable —
governance reads many of these at once.

```markdown
## Done
- <what happened, with relative timestamps>

## Problems
- <blockers/issues that did not become frictions — if one deserves action, it should
  have been a friction; say so>

## Insights
- <decisions made and why · learnings worth keeping>

## Context gaps
- **<gap title>** — what was discovered · where it should live · kind
  (see context-gaps.md for the kinds)
```
