# Context gap patterns

A context gap = knowledge surfaced in the session that has no proper home yet. The
four kinds governance knows how to drain:

1. **Knowledge with no place** — a fact/decision/reference that lives only in the
   conversation. Where should it live? (a bucket, the graph, a doc)
2. **Undocumented process** — something was done by improvising steps that will be
   needed again. Candidate for a runbook or a skill.
3. **Skill candidate** — a repeated method crystallized enough to become a library
   skill (name it; sketch the trigger + steps).
4. **Inadequate structure** — the graph itself got in the way (a purpose missing,
   a bucket in the wrong place, an assignment gap). Governance owns this one.

For each gap record: what was discovered · where it should live · the kind.
